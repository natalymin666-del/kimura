# Design-Partner Pilot Onboarding Checklist

A customer can determine initial participation readiness in approximately ten
minutes:

- Does the agent use tools or other bounded actions?
- Can the tool schemas and canonical argument rules be supplied?
- Is a synthetic twin or non-production sandbox available?
- Can test identities and synthetic data be created?
- Can state changes and effects be observed independently?
- Can the environment be reset or rolled back between paired tests?
- Are relevant authorization policies, roles/scopes, and business rules available?
- Can the customer provide written authorization for the bounded assessment?
- Are production targets and credentials excluded from the pilot scope?
- Is a technical incident/escalation contact assigned?

A “no” answer is a precondition to resolve, not permission to broaden scope.
